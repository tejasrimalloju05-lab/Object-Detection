# Object Detection

## Overview

This project demonstrates real-time object detection using Python and OpenCV. It processes images or video to identify and locate objects by drawing bounding boxes around detected objects.

## Features

* Detects objects in images or video
* Displays bounding boxes around detected objects
* Real-time detection using OpenCV
* Easy to modify for different object detection models

## Technologies Used

* Python
* OpenCV
* NumPy
* Jupyter Notebook

## How to Run

1. Install the required Python libraries.
2. Open the Jupyter Notebook.
3. Run all the cells.
4. Upload an image or use a video source to perform object detection.

## Future Improvements

* Integrate YOLO for improved accuracy.
